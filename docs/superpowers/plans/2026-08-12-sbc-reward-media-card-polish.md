> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish reward-player art for player SBCs and compact the SBC listing cards to the approved WordPress-refined behavior.

**Architecture:** The n8n workflow remains the media-selection boundary and emits one validated media URL per product. React keeps the existing catalog contract; the listing omits descriptions and CSS owns compact equal geometry and progressive hover/reduced-motion behavior.

**Tech Stack:** n8n workflow JSON generated by Node scripts, Vitest/Node tests, React/Inertia, CSS, Pest.

## Global Constraints

- Player rewards use approved `rewardImgURL`; non-player rewards retain challenge `imageURL`.
- No pack/Player Pick substitution.
- No production code before a failing regression test.
- Preserve mirrored-media allowlisting and last-good fallback.
